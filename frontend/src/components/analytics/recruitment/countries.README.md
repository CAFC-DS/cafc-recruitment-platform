# Map boundary data

Source: https://github.com/datasets/geo-countries/blob/master/data/countries.geojson

Natural Earth country boundaries, retrieved 27 October 2026. Simplified locally with a 0.25-degree Douglas–Peucker tolerance and rounded to one decimal in a 1080 × 540 equirectangular coordinate space. Only exterior rings are retained. Approximate marker centres use the largest polygon's bounding-box centre; England, Scotland, Wales and Northern Ireland use explicit approximate country centres. These are country-level aggregates, not club coordinates. No map service or third-party request is made when the page renders.
